# Chapter 3 additions

Heartbeat.wav was synthesized locally for this project from two short decaying low-frequency pulses. No speech, third-party recording or imported sample is included. Existing Foley SoundSets retain their prior recorded asset provenance.

Decal textures and additional prop geometry were generated by SchoolAbandonmentPass with native Unity APIs. No Meshy or external 3D model generation was used.
